# دليل خامات الكهرباء — Android Native

تطبيق أندرويد أصلي (Kotlin + Jetpack Compose + Room) بواجهة عربية من اليمين للشمال، وصفوف صغيرة لعرض الأصناف، دون WebView.

## البيانات المرفقة

- **181 خامة** داخل 13 قسمًا؛ مأخوذة من النسخة V12 من الموسوعة.
- **403 عرض سعر** كما وردت في قاعدة V12؛ فيها عروض مصرية وبعض أسعار مصانع أجنبية بالعملة الأصلية.
- **730 مدخل شركة مرشحة**؛ وجود اسم الشركة لا يعني اعتماد توفر موديل محدد.
- **29 صورة مرتبطة سابقًا** بروابط خارجية تحتاج اتصالًا؛ باقي الصور يمكن إضافتها من الجهاز والكاميرا.
- معلومات الشرح والمواصفات والاختيار والتركيب والتحذيرات والمرجع النصي لكل فئة.

تبدأ البيانات من ملف `app/src/main/assets/catalog.json`، وتُستورد إلى Room عند التشغيل الأول. أي تعديلات لاحقة تُحفظ محليًا، ولا يُعاد الكتابة فوقها بعد إغلاق التطبيق.

## الشاشات

- الأقسام والبحث والفلاتر والمفضلة: صفوف صغيرة تحتوي صورة مصغرة واسمًا ووصفًا قصيرًا.
- تفاصيل الصنف: تعريف؛ مواصفات؛ تركيب؛ شركات وأسعار؛ ملاحظاتي. التبويبات قصيرة بدل عرض الصفحة كلها مرة واحدة.
- صور الصنف: إضافة من المعرض، التصوير بالكاميرا، حذف الصورة، تعيين الصورة الرئيسية.
- تعديل اسم الصنف وبياناته الفنية، وإضافة وحذف أصناف جديدة.
- إدارة عروض الأسعار والموردين والموديلات والماركات وتقييم شخصي للجودة والشهرة.
- نسخة احتياطية ZIP عبر Android Storage Access Framework تشمل قاعدة البيانات المحلية والصور المضافة من الجهاز. والاسترجاع يستبدل البيانات الحالية، فخُذ نسخة قبل الاستيراد.
- واجهة عربية RTL، وضع فاتح/داكن، وبيانات تعمل من غير إنترنت عدا الصور الخارجية والمواقع.

## تشغيله في Android Studio

1. افتح مجلد `FayrozElectricalGuide_Android` كمشروع Gradle في Android Studio.
2. يحتاج Java 17، وAndroid SDK Platform 35 وBuild Tools 35.0.0، وGradle 8.11.1، واتصالًا بالإنترنت لتنزيل الاعتمادات أول مرة.
3. على Windows يمكن تشغيل `powershell -ExecutionPolicy Bypass -File tools/build-windows.ps1` بعد ضبط Android SDK؛ وعلى macOS/Linux شغّل `bash tools/build-linux-macos.sh`. أو نفذ `gradle :app:assembleDebug` إذا كان Gradle مثبتًا، أو ابنه من قائمة Build في Android Studio.
4. سيتولد ملف `app/build/outputs/apk/debug/app-debug.apk` بعد نجاح البناء.
5. يوجد Workflow في `.github/workflows/build-android.yml` لبناء APK تلقائيًا بواسطة GitHub Actions عند رفع المشروع إلى مستودعك.

**ملحوظة بناء:** بيئة إنشاء هذا المشروع لا تحتوي Android SDK/Gradle، لذلك لم يمكن إنتاج أو اختبار APK فعلي هنا. السورس يحتاج أول Gradle Sync/build على بيئة Android. هذا مشروع مصدر قابل للتعديل وليس APK موقّعًا جاهزًا للتثبيت.

## حماية بيانات المستخدم

- تعديلاتك والأسعار والصور المحلية تُحفظ داخل التطبيق، ولا تتطلب حسابًا.
- لا تمسح بيانات التطبيق قبل تصدير النسخة الاحتياطية.
- الصور الأصلية البعيدة مرتبطة بروابط مصادرها؛ إضافة الصور الخاصة بك تحفظ نسخة فعلية داخل ملفات التطبيق.
- أسعار V12 للاستدلال، وليست أسعار تعاقد أو عروضًا حية. يجب مراجعة رابط المورد والمقاس والوحدة وحالة الضريبة قبل الشراء.

## خطة تحسين قبل النشر التجاري

- بناء Debug APK واختبار Compose يدويًا على أجهزة صغيرة ومتوسطة.
- اختبارات استيراد/تصدير ZIP الكبيرة، وتعديل الصور وإعادة التشغيل، ثم توقيع Release.
- ترقية لاحقة: زر إضافة صورة رئيسية فور التقاطها، وإجراءات تراجع عن الحذف، ومطابقة وفصل العلامات التجارية عن موردي البيع، واختبارات تحويل قواعد البيانات للإصدارات التالية.
